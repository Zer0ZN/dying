# 配乐 / Soundtrack

场景本身带一首**原创的实时生成氛围曲**（WebAudio 现场合成：A 小调 add9 铺底、稀疏的毡音钢琴、湖面风声），
所以开箱即可听到音乐，且不需要任何音频文件。

如果你拥有 **《the rescue》 – Antent / Nectry** 的授权音频，把文件放在这个目录下：

```
assets/the-rescue.mp3     （或 .ogg / .m4a / .wav）
```

页面加载时会自动探测；一旦存在，就会改为循环播放这首曲子，否则继续用生成的氛围曲。
两种模式都通过右上角的「♪ 音乐」按钮或键盘 **M** 开关，默认静音，需要用户点击后才开始播放
（浏览器的自动播放策略要求如此）。
